# Records

The working records behind the paper, kept for transparency. The repository front page is the README one level up.

- `AUDIT.md`: the number-by-number audit. Every cell of Tables 1 and 2 and every number in the text, with its file,
  sample size, estimator and status, including the places where the submitted text and the files differ.
- `DISCREPANCIES.md`: every issue found during the checks and how it was resolved.
- `MANIFEST.txt`: every file in the repository with its size and where it came from.
- `reports/`: run reports and logs of the numbered check rounds (PART 5 to PART 27).
- `checks/`: checks of the compiled paper: values, fonts, page limit and Figure 1.
- `history/`: earlier project history, brought in unchanged for the record.
- `results/`, `summary/`: tables and value snapshots of earlier drafts, superseded.
- `archive/`: the companion page of the first release.

Files written before 12 October 2026 cite these folders without the `records/` prefix.
